Integration surfaces

Connect an existing harness to one deterministic evidence contract. TraceGate never borrows an agent credential or executes a tool on its behalf.

CLI Command lineCompile, replay, evaluate, redact, sign, and record a human decision locally. Open guide
API Typed HTTP APIFastAPI and OpenAPI expose the same Pydantic contracts used by the CLI. Checking
GH GitHub ActionRun the gate in CI and upload compilation and verification receipts as build artifacts. Set up
TS TypeScript clientGenerated from the committed OpenAPI document and checked for contract drift in CI. Open client
OT OTLP GenAI importNormalize one pinned OpenTelemetry GenAI revision into the provider-neutral experiment manifest. Open guide
SIG Signed receipt bundlesOptional Ed25519 signing binds an artifact to repository, commit, signer, and trusted-key policy. Open guide

Browser, email, shell, and deployment connectors are intentionally outside this trusted core. A future AWE Workspace may orchestrate them behind explicit permissions while TraceGate remains the independent promotion gate.
