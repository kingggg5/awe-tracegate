# Archived product material

This directory preserves pre-v0.3 product notes and Skills that arrived from
the historical `main` branch while PR #11 was being reconciled.

Nothing under this directory is installed, packaged, generated into the Claude
Code adapter, or treated as an active TraceGate workflow. The supported plugin
surface is the five canonical Skills in [`../../skills/`](../../skills/).

The archive can be removed in a later major cleanup after maintainers confirm
that no migration or attribution history is still needed.
